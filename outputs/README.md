# Generated results

The scripts create these subfolders automatically:

- `figures/`: EDA and model-performance PNG charts
- `metrics/`: CSV comparisons, grouped errors, and feature importance
- `predictions/`: the locked-test predictions and one-hour scenarios
- `reports/`: plain-language Markdown findings and experiment metadata

Generated outputs are ignored by Git by default. For a PhD application, you may
deliberately commit a small, final selection of figures and reports after
reviewing them.
